# VECTOR: BLACKLINE — Base 3D Asset Pack

Original procedural GLB assets intended for the `vector/assets/` directory.

## Integration
Copy the category folders into `vector/assets/`. Load GLB files with your existing Three.js/Babylon.js GLTF loader.

## Important
These are functional base meshes with embedded materials. Character meshes are static and do not include a skeleton or animation clips. They are suitable as an initial asset layer while higher-fidelity production models are developed.
